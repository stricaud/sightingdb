Reach it from your machine:

  kubectl --namespace {{ .Release.Namespace }} port-forward svc/{{ include "sightingdb.fullname" . }} {{ .Values.service.port }}:{{ .Values.service.port }}

Then the management interface is at
{{ ternary "https" "http" (eq (include "sightingdb.tlsEnabled" .) "true") }}://localhost:{{ .Values.service.port }}/_management/

Your admin key{{ if not .Values.acl.keys }}, generated on install and kept across upgrades{{ end }}:

  kubectl --namespace {{ .Release.Namespace }} get secret {{ include "sightingdb.aclSecretName" . }} \
    -o jsonpath='{.data.admin-key}' | base64 -d; echo

Write and read a sighting:

  curl -k -H "Authorization: <key>" "{{ ternary "https" "http" (eq (include "sightingdb.tlsEnabled" .) "true") }}://localhost:{{ .Values.service.port }}/w/my/namespace?val=127.0.0.1"
  curl -k -H "Authorization: <key>" "{{ ternary "https" "http" (eq (include "sightingdb.tlsEnabled" .) "true") }}://localhost:{{ .Values.service.port }}/r/my/namespace?val=127.0.0.1"

Check it works:

  helm test {{ .Release.Name }} --namespace {{ .Release.Namespace }}

{{- if not .Values.persistence.enabled }}

WARNING: persistence is off. The database is held in memory and snapshotted to
an emptyDir, so everything is lost when the pod is replaced. Set
persistence.enabled=true for anything you mean to keep.
{{- end }}
