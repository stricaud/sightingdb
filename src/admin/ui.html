A namespace is a path, so feeds/misp/ips browses like folders: folder means other namespaces sit underneath it, namespace means it holds values of its own, and a path can be both. A tier applies to the whole top-level namespace, so changing it for myorg/one changes myorg and everything under it. hot stays in memory; warm is dropped once untouched for the configured window; cold is dropped at the next sweep. Evicted data is read back automatically when it is next used.

Leave the TTL blank to keep whatever expiry a value already had, or set 0 to clear it. Leave the time blank to record the values as seen now. Writing a namespace that does not exist creates it.
